# 夢想實現計畫

可獨立使用的繁體中文投資情境比較工具。純 HTML、CSS、JavaScript；沒有建置步驟、套件依賴、資料庫或後端。

## 專案內容

- 完整網站程式：`index.html`（頁面、樣式、計算和事件均在同一檔）。
- 網站圖示：`favicon.svg`。
- ETF／基金參考名錄：`catalogue.json`。
- 程式架構：`docs/ARCHITECTURE.md`。
- GitHub 上傳與發布說明：`docs/GITHUB.md`。
- 開發筆記和現有限制：`docs/HANDOFF.md`。
- 不需安裝套件的程式測試：`tests/smoke.cjs`。

## 使用方式

解壓縮後，以瀏覽器開啟 `index.html` 即可使用。所有金額計算在使用者瀏覽器執行。

需要 HTTP 測試環境時，可在此資料夾執行：

```sh
python3 -m http.server 8080
```

再開啟 http://localhost:8080 。Python 只用於本機測試，網站發布本身不需要 Python。

若已安裝 Node.js：

```sh
node tests/smoke.cjs
```

## 已有功能

- 定期定額／單筆投入切換。
- 三方案名稱與假設年率由使用者自行填寫。
- 年、半年、季、月複利；單利模式。
- 累積本金與選填年率的獨立本利合試算。
- 資產成長曲線、年份滑桿、單一方案曲線。
- 期末本利合最高方案採實線；並列最高都採實線。
- 早開始／晚開始比較、選填比較年期。
- ETF／基金名稱搜尋與三方案比較。
- 定期定額本利和（#growth）：每月投入、平均年報酬率、年數，算出期末本利和、價差收益、逐年明細與成長圖；可切換「只賺價差」或「有月配息」（單筆投入、年化配息率、淨值漲跌幅、領出現金／滾入再投入，顯示期末每月可領配息與含息年化總報酬）。
- 首頁為人生曲線圖；人生曲線、通膨、月配息頁的左側輸入與右側結果各自獨立捲動。
- 生活需求以食衣住行育樂計算：食＝每日餐費×30×12×年數；衣＝每月生活費×12×年數；住＝租房（房租×12×年數）或買房（房價）；行＝(第一台＋最後一台)÷2×台數（每 N 年換一台）；育＝小孩花費；樂＝(歐洲次數×費用＋亞洲次數×費用)×旅遊年數，皆從退休那天起算（育、買房依填寫年齡）。
- 通膨怎麼來（#inflation）：通膨計算機、台灣近年 CPI 年增率（主計總處）、通膨成因說明，可一鍵套用到人生曲線圖。
- 人生曲線圖（#life）：目前年齡、退休年齡、規劃年齡、資產、每月投入、退休前後報酬率、退休生活費與其他收入、通膨，加上最多 8 個人生夢想；畫出從現在到晚年的資產曲線，標示夢想、退休與資產用完的年齡，並反推需要的每月投入。
- 開場動畫：每次開啟分頁播放一次，點擊可略過；系統設定減少動態時不播放。
- 深色（黑金）與淺色（象牙金）兩種主題，預設深色，可於頁首切換並記住選擇。
- 電腦版分類選單、投入設定與結果獨立捲動；手機單欄。

## 發布

詳細步驟見 [GitHub 說明](docs/GITHUB.md)。請上傳解壓縮後資料夾內的檔案，不要只上傳 ZIP。

首頁必須在儲存庫根目錄直接看得到 `index.html`。使用 GitHub Pages 的 `main` 分支與 `/(root)` 目錄發布，不需要自己的網域。

## 重要提醒

試算假設，非保證收益；未另扣費用、稅負、通膨與換匯成本，固定報酬曲線不代表真實市場波動。

名錄目前 28 筆，不是即時行情。部分標的附有發行公司官網公布的累積報酬（`perf` 欄位），網站換算為年化報酬並可一鍵帶入年率；數字需每月依官網或月報手動更新，並同步 index.html 內的 catalogue 常數與 catalogue.json。查不到可手動輸入。

目前沒有客戶名單收集、資料持久化、帳號、稅額試算或保單功能。請勿將客戶個資或私密檔案提交到公開 GitHub 儲存庫。
