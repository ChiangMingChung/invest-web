# 程式架構與計算邏輯

## 1. 技術架構

本版本是純靜態前端，非 React／Next.js。瀏覽器載入 HTML、CSS 和 JavaScript 後，輸入、計算、圖表與搜尋均在前端完成。沒有伺服器 API、資料庫、身分驗證、寫入客戶資料、localStorage 或 sessionStorage。

| 檔案 | 角色 |
| --- | --- |
| index.html | 網頁結構、所有 CSS、內嵌 JavaScript、內嵌 28 筆名錄（含官方累積報酬） |
| favicon.svg | 瀏覽器頁籤圖示 |
| catalogue.json | 名錄的獨立參考副本；目前執行時不會 fetch 此檔案 |
| .nojekyll | 告知 GitHub Pages 不需要 Jekyll 處理 |
| docs/ | 架構、GitHub 操作、開發筆記 |
| tests/smoke.cjs | 以 Node.js VM 與最小 DOM 替身檢查計算和線型 |

## 4. 投入與報酬公式

符號：p 為一次本金，m 為每月投入，y 為年數，n＝12y，a＝輸入年率÷100。

- 定期定額：p＝0，從下個月月底開始投入，共 n 筆。
- 單筆：m＝0，本金現在一次投入。
- 累積投入本金：p＋mn。
- 收益：期末金額－累積投入本金。
- 年率留白：對應方案不計算，不當成 0%；明確填 0 才是零報酬。

### 複利

年、半年、季、月的每年複利次數 f＝1、2、4、12，每期月數 l＝12/f，每期利率 i＝a/f。

程式以期末複利規則計算：

```text
periodDeposits = m × [l + (a / 12) × l × (l - 1) / 2]
growth = (1 + i)^(yf)
FV = p × growth + periodDeposits × (growth - 1) / i
```

i＝0 時直接使用 p＋mn。y＝0 時返回 p。

這裡定期投入「仍每月投入」，複利頻率只決定每何時把收益併入本金。期內本金按月計息，當期收益不再計息，期末才併入本金。不是每半年／每季才投入一次，也不是將最後一期額外算利息。

實作採 `Math.log1p` 與 `Math.expm1`，降低小利率時的數值誤差。

### 單利

```text
FV = p × (1 + ay) + m × [n + a × n × (n - 1) / 24]
```

收益不再計息，所以複利頻率選單停用。負年率下此公式可能得到負資產，網站已揭露為數學試算結果。

### 早晚比較

比較期間 h 取選填年期；留白沿用主年期。晚開始 d 年後，實際投資期間為 max(0,h-d)。

早開始 FV＝calculateFinal(p,m,h,...)；晚開始 FV＝calculateFinal(p,m,max(0,h-d),...)。

若晚開始超過比較終點：定期投入尚未開始，金額為 0；單筆本金保留為不計息現金 p。差距拆成期末金額、本金與收益。

## 5. 圖表規則

- SVG 路徑依每年期末計算值繪製。
- 以完整主年期最後一年的本利合判定最高，不隨查看年份滑桿改變排名。
- 最高方案採實線；並列最高皆採實線。
- 其他方案依期末金額排序，採長虛線或點線；本金另採灰色虛線。
- 滑桿顯示指定年度的金額，不重新設定主年期。
- 相同計算結果的線會重疊，可選單一方案查看。
- 瀏覽器視窗變更時重繪。

## 7. 名錄與風險揭露

名錄內嵌在 index.html 的 catalogue 常數。catalogue.json 是同資料的副本，修改名錄時兩邊需同步。

目前 28 筆標的，非即時行情。`perf.returns` 記錄發行公司官網公布的近 1／2／3／5 年累積報酬（%），`perf.asOf` 為資料日期；`annualized()` 以 (1＋累積報酬)^(1/年數)−1 換算年化，超過 100% 年率上限者不提供帶入。數字為手動更新，不在執行時抓取外部資料。名稱、幣別、級別與配息方式仍應自行確認。

本工具不提供商品建議或保證收益，未計算稅法、交易／管理費、通膨或匯率。
