# 開發筆記與已知限制

## 修改位置

- 配色：index.html 中 CSS 的 --a、--b、--c，以及 JavaScript colors 陣列，兩者需同步。
- 桌機三區／手機單欄：CSS 的 Quiet financial workspace 區塊。
- 計算：calculateFinal、calculate。
- 最高實線：curveStyles、draw。
- 即時更新：render、pending、各 input/change 事件。
- 分頁：setPage、pageSettings。
- 標的搜尋：catalogue 常數、searchCatalogue、showSuggestions、renderCatalogue。
- 預設投入值：HTML value 與 reset 事件，兩者需同步。

程式為單一檔案、無外部框架。可在未來重構為 CSS／JS 模組。

## 已知範圍與限制

- 主投資年期仍為 1～60 整數，並非所有年期都無上限。
- 早晚比較的晚開始年數／選填年期沒有業務上的最大年數限制，但必須是非負／正安全整數；浮點數能力仍有上限。
- 金額与方案年率有表單範圍限制，見 HTML min/max。
- 非法主輸入時，會顯示錯誤、清除早晚比較並隱藏快速结果，但部分主卡片或曲線可能仍顯示前一次有效試算，後續開發應改進為統一清空或標示「上次有效結果」。
- 主卡片／曲線對極端輸入的 Infinity 處理不如早晚面板完整；不應視為任意規模的精密金融引擎。
- 浮點計算，最後金額四捨五入，圖表顯示萬元；不是逐筆金融帳務結算。
- 名錄不即時更新；無績效 API、稅法 API、資料庫、保單功能。
- 不保存客戶個資；未建置第二版名單表單。
- smoke 測試是最小 DOM 模擬，不代替真實瀏覽器／RWD／可及性驗收。

## 建議驗收

1. 定期每月 10,000、20 年：本金為 2,400,000，不多算第一筆。
2. 明確填 0%：本利合等於本金；年率空白顯示破折號。
3. 任意方案年率調高至最高：實線跟著換；並列最高均為實線。
4. 切換單筆／定期，沒有同時額外加入另種本金。
5. 切換四種複利頻率：主卡、快速試算、早晚比較一致更新。
6. 晚開始年數 0、5、大於比較期間：本金、收益差距分開且正確。
7. 手機和桌機檢查溢位、捲動、選单、搜尋鍵盤操作。
8. #scenarios 和 #targets 切換，分頁名稱與年率互不覆蓋。
